# PUZZLEMIND
Puzzlemind es un juego en el cual respondes preguntas para poder avanzar a la meta, preguntas de todo tipoy para todas las personas.

# ANALISIS
Este juego tendrá como inspiración diversos títulos populares de consola 
enfocados en la diversión y el progreso del jugador. Consistirá en un videojuego educativo 
desarrollado para consola, en el que el usuario deberá superar diferentes desafíos para 
obtener puntos, desbloquear nuevos niveles y mejorar su desempeño. 

El juego contará con una progresión de dificultad, iniciando con niveles sencillos y 
avanzando gradualmente hacia retos más complejos. A lo largo de la experiencia, el jugador 
encontrará actividades relacionadas con matemáticas, ciencias naturales, ciencias sociales 
y cultura general, presentadas mediante dinámicas interactivas y entretenidas.

# REQUERIMENTOS
Requerimientos funcionales:
1. El sistema debe permitir al jugador iniciar una nueva partida.  
2. El sistema debe permitir guardar y cargar el progreso del jugador.  
3. El juego debe presentar diferentes niveles organizados por dificultad.  
4. El sistema debe desbloquear nuevos niveles cuando el jugador complete los requisitos del 
nivel anterior.  
5. El juego debe mostrar desafíos educativos relacionados con:  
o Matemáticas.  
o Ciencias naturales.  
o Ciencias sociales.  
o Cultura general.

Requerimientos no funcionales:
Usabilidad 
1. La interfaz debe ser sencilla e intuitiva para niños de 8 a 12 años.  
2. Los textos, botones e íconos deben ser claros y de fácil comprensión.  
3. El juego debe ofrecer instrucciones visuales y fáciles de seguir.  
Rendimiento 
4. El tiempo de carga de los niveles no debe superar los 5 segundos.  
5. El juego debe responder a las acciones del jugador en menos de 1 segundo.

# DISEÑO (DIAGRAMA DE FLUJO)
El diseño del juego es muy sencillo, iniciamos con un menú sencillo donde elegimos si salir o iniciar el juego, una vez iniciamos el juego seleccionamos el nivel y procedemos a seleccionar la categoría y comienza el juego, ya dependiendo si respondes bien o mal, avanzas o pierdes.

# CODIGO
El código es bastante sencillo se basa en lenguaje de Python y todo vía texto utilizando muchos ciclos whyle y operadores logicos.
