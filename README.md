ANALISÍS
Este juego tendrá como inspiración diversos títulos populares de consola 
enfocados en la diversión y el progreso del jugador. Consistirá en un videojuego educativo 
desarrollado para consola, en el que el usuario deberá superar diferentes desafíos para 
obtener puntos, desbloquear nuevos niveles y mejorar su desempeño. 

REQUERIMENTOS
El sistema debe permitir al jugador navegar por el menú e iniciar y terminar la partida

DISEÑO
Un diseño simple y sencillo debido a las limitaciones de python pero entretenido basado en codigo de texto y comandos via texto

CODIGO
El código se basa en comandos lógicos es decir si decido algo se hace y si no se va por otro camino
